# Processed Data Arrays & Tensors Directory (`processed_tensors/`)

This directory stores all standardized intermediate data structures, feature tensors, distance matrices, and statistical results generated by the longitudinal analysis pipeline for the $N = 19$ infant cohort.

* **Axis 1 (Sessions, $S=2$):** `0: ses-1`, `1: ses-2`.
* **Axis 2 (Epochs, $K=12$):** Chronological artifact-free segments ($k = 0 \dots 11$, corresponding to segments 1 to 12).
* **Axis 3 (Elements, $n$):** 
  * $n = 19$ for node features (standard region order: `F, C, T, P, O`).

### B. Pairwise Element Jaccard Arrays: `J_pair_{fid}_{ses}.npy` (52 Files)
For each feature set and session (`ses-1` or `ses-2`), stores element-level weighted Jaccard similarity across all 171 pairs:
$$\text{Shape: } (171, n)$$
* **Axis 0 (Infant Pairs, $\binom{19}{2} = 171$):** Canonical ordering from `itertools.combinations`.
* **Axis 1 (Elements, $n$):** 19 nodes or 171 edges.

---

### C. Cohort Distance Matrices: `S_mat_{fid}_{ses}.npy` (52 Files)
Stores recording-level similarity across all elements:
$$\text{Shape: } (19, 19)$$
* **Rows and Columns ($19 \times 19$):** Infants in fixed alphanumeric order.
* **Diagonal Entries:** `NaN`.

---

### D. Within-Session Split-Half Arrays: `W_elem`, `O_elem`, `diff_within_elem` (156 Files)
$$\text{Shape: } (19, n)$$
* **`W_elem_{fid}_{ses}.npy`:** Split-half self-similarity (first 6 epochs vs second 6 epochs) for each infant and element.
* **`O_elem_{fid}_{ses}.npy`:** Matched others baseline (comparing each infant's first 6 epochs against all other infants' second 6 epochs).
* **`diff_within_elem_{fid}_{ses}.npy`:** Short-term within-session identifiability difference: $W - O$.

---

### E. Cross-Session Longitudinal Identifiability Matrices & Tensors (78 Files)
* **`M_mat_{fid}.npy` / `M_{fid}.npy` (52 files):**
  $$\text{Shape: } (19, 19)$$
  Cross-session recording-level weighted Jaccard similarity $M[a, b] = S_{(a, 1), (b, 2)}$ where row $a$ is infant $a$ at `ses-1` and column $b$ is infant $b$ at `ses-2`.
  * **Diagonal ($a = b$):** Longitudinal self-similarity ($I_{\text{self}}$).
  * **Off-diagonal ($a \ne b$):** Longitudinal between-subject similarity ($I_{\text{others}}$).
* **`M_elem_{fid}.npy` (26 files):**
  $$\text{Shape: } (19, 19, n)$$
  Element-level cross-session similarity tensor $M_e[a, b] = J_{(a, 1), (b, 2)}(e)$.
  Averaged across diagonal to yield $I_{\text{self}}(e)$ and off-diagonal to yield $I_{\text{others}}(e)$, defining element-level differential identifiability $I_{\text{diff}}(e) = (I_{\text{self}}(e) - I_{\text{others}}(e)) \times 100$.

---

### F. Axis Combination: Taxonomy & State-Trait Variance (2 JSON Databases)
* **`taxonomy_results.json`:**
  Stores 4-quadrant functional classification for each element across all 26 feature sets:
  * **Universal Core:** $q_{U_1}(e) < 0.05 \land q_{U_2}(e) < 0.05 \land q_{I_{\text{diff}}}(e) \ge 0.05$
  * **Individual Marker:** $\neg(q_{U_1} < 0.05 \land q_{U_2} < 0.05) \land q_{I_{\text{diff}}}(e) < 0.05$
  * **Universal & Individual:** $q_{U_1}(e) < 0.05 \land q_{U_2}(e) < 0.05 \land q_{I_{\text{diff}}}(e) < 0.05$
  * **Neither / Redundant:** Non-significant on both axes.
* **`variance_results.json`:**
  Stores three-way variance partitioning proportions ($\text{Prop}_{\text{Trait}}, \text{Prop}_{\text{Session}}, \text{Prop}_{\text{Epoch}}$) fitted via Linear Mixed-Effects Models ($y = \mu + u_a + v_{a, s} + \varepsilon$) on rank-based inverse-normal transformed features across 456 observations, along with age-adjusted models and convergence diagnostics.

---

### G. Developmental Trajectories & Twin/Sibling Analysis (2 JSON Databases)
* **`developmental_results.json`:**
  Stores developmental shift $\Delta U = U_2 - U_1$, 95% bootstrap CIs, Mantel matrix tests between pairwise similarity $S$ and chronological age difference matrix $D$ (10,000 permutations), and inter-session time gap correlations ($M[a, a]$ vs $\Delta\text{days}$), including individual audits for short-interval infant `sub-NORB00064` (4 days) and intermediate infant `sub-NORB00069` (42 days).
* **`twin_results.json`:**
  Stores male twin pair audit (`sub-NORB00086` & `sub-NORB00087` — Table T6):
  * Sibling similarity $S_{(86, s), (87, s)}$ and percentile rank among all 171 pairs in each session.
  * Rank among matched infant controls (34 pairs involving either sibling).
  * Rank among age-matched non-sibling controls ($|\Delta\text{age}| \le 7$ days).
  * Cross-session cross-identification check ($M[86, 87]$ and $M[87, 86]$).
  * Elements where twin similarity exceeds the 95th percentile of non-sibling pairs in both sessions.

---

### H. Robustness & Sensitivity Checks Database
* **`robustness_results.json`:**
  Stores the 88 sensitivity check evaluations across all 9 methodological variations (matching Table T4):
  * **Check 1 (0/0 Rule):** $0/0 \to 0$ replacement vs undefined exclusion.
  * **Check 2 (Combinatorial Pairing):** All $12 \times 12 = 144$ epoch combinations vs diagonal $(k, k)$.
  * **Check 3 (Window Length):** Truncated $K = 6$ epochs vs $K = 12$.
  * **Check 4 (Twin Exclusion):** Recomputed on $N = 17$ independent infants (excluding twin pair).
  * **Check 5 (Pattern-Only Normalization):** $L_1$-normalized feature vectors ($\sum_e x(e) = 1$).
  * **Check 6 (Reference Montage):** Continuous EEG re-referenced to average reference.
  * **Check 7 (Volume Conduction Control):** Debiased weighted Phase Lag Index (dwPLI) vs Pearson $|r|$.
  * **Check 8 (Fixed-Density Binarization):** Fixed top-58 strongest edges vs GCC adaptive thresholding.
  * **Check 9 (Physical Distance Control):** 3D Euclidean inter-electrode distance residualized out of edge connections.
