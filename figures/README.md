# Publication Figures: Longitudinal Infant EEG Network Constituents

This directory contains the complete set of vector PDF figures and high-resolution (300 DPI) PNG figures for the manuscript, corresponding to **Phase 9** of the analysis pipeline.

All figures were rendered using Matplotlib with publication-grade font embedding (TrueType / Type 42), consistent font sizing (`DejaVu Sans`), and standardized color palettes.
